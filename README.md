# Mar & Rios Caixa — Downloads

Distribuição do aplicativo de caixa da Peixaria Mar & Rios, Xangri-lá/RS.

[Baixar o instalador para Windows](https://github.com/susfghvyuj/mar-e-rios-atualizacoes/releases/latest/download/MarERiosCaixa-Setup.exe)

[Ver versões disponíveis](https://github.com/susfghvyuj/mar-e-rios-atualizacoes/releases)

Instale a versão 1.1.1 uma vez para ativar o novo canal de atualizações. Depois, o aplicativo verifica novas versões ao abrir e a cada quatro horas, baixa a atualização e instala quando a frente de caixa estiver sem atendimento em andamento. Não é necessário configurar token nem entrar no GitHub.

Produtos, clientes e vendas ficam no computador. O instalador preserva os dados existentes, e o aplicativo faz uma cópia de segurança antes das atualizações automáticas.

Este repositório disponibiliza somente arquivos de instalação, atualização e documentação de distribuição. O código do aplicativo continua em um repositório privado.

Requisitos: Windows 10 ou 11 com .NET Framework 4.8. Para impressão, instale o driver Windows da Epson TM-T20X e selecione a impressora no aplicativo.
